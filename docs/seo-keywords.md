## On-Page SEO Checklist (per page)

- [ ] `<title>` contains primary keyword, ≤60 chars
- [ ] Meta description ≤155 chars, includes keyword + CTA
- [ ] H1 appears once and contains the primary keyword
- [ ] First paragraph includes primary keyword naturally
- [ ] Images have descriptive `alt` text (no "image1.jpg")
- [ ] Internal links to related pages/services
- [ ] Schema.org JSON-LD block in `<head>` (type matches page)
- [ ] Canonical URL set (wagtailseo handles this automatically)
- [ ] OG tags present (wagtailseo handles this automatically)

---

## Technical SEO Checklist

- [ ] `sitemap.xml` accessible at `/sitemap.xml`
- [ ] `robots.txt` accessible at `/robots.txt` (allows all, points to sitemap)
- [ ] Site submitted to [Google Search Console](https://search.google.com/search-console)
- [ ] Site submitted to [Bing Webmaster Tools](https://www.bing.com/webmasters)
- [ ] Core Web Vitals green in PageSpeed Insights
- [ ] Mobile-friendly test passed
- [ ] HTTPS enforced (redirect HTTP → HTTPS)
- [ ] No broken links (check with Screaming Frog or similar)
- [ ] Images served in WebP format where possible
- [ ] Register on [Firmy.cz](https://www.firmy.cz) (Czech market)
- [ ] Create Google Business Profile (local SEO)

---

## Content Strategy Notes

- Publish 1–2 blog posts per month targeting long-tail question keywords
- Each post should end with a CTA linking to the booking page
- Internal linking: blog posts → services pages → booking
- Over time, build topical authority in: emotional regulation, generational patterns, child behaviour, conscious parenting techniques
